# Nuray Güneş Mühendislik Danışmanlık Web Sitesi

Bu paket, Nuray Güneş Mühendislik Danışmanlık Limited Şirketi için hazırlanmış statik ve mobil uyumlu kurumsal web sitesi taslağıdır.

## Dosyalar

- `index.html`: Ana web sayfası
- `style.css`: Tasarım ve responsive stil dosyası
- `script.js`: Mobil menü ve animasyonlar
- `assets/logo-nuray-gunes.png`: Logo
- `assets/favicon.png`: Site simgesi

## Kullanım

1. Klasörü bilgisayarınıza çıkarın.
2. `index.html` dosyasını tarayıcıda açın.
3. Yayına almak için tüm dosyaları hostinginizin `public_html` veya ilgili ana dizinine yükleyin.

## Not

İletişim formu şu anda `mailto:` yöntemiyle çalışır. Profesyonel yayında PHP, Formspree, Netlify Forms veya benzeri sunucu tabanlı form entegrasyonu önerilir.
